# KAI 🤖

Простой AI-чат без регистрации с голосовым вводом.

## Запуск

Можно открыть `index.html` напрямую или разместить репозиторий через GitHub Pages.

## Возможности

- чат без регистрации;
- адаптивный интерфейс;
- голосовой ввод через Web Speech API;
- русский язык по умолчанию;
- готовая структура для подключения AI backend.

> API-ключи не должны находиться в `app.js` или другом клиентском файле. Для Mistral/GigaChat/YandexGPT лучше использовать серверный backend.
