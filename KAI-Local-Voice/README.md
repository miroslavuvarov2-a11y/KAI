# KAI Local Voice

Локальный голосовой помощник Windows без OpenAI API и без оплаты API.

Схема: микрофон → браузер → локальный сервер → Ollama → управление Windows → голосовой ответ.

## Установка

1. Установи Ollama для Windows: https://ollama.com/download/windows
2. Запусти `setup.bat`.
3. Дождись загрузки модели `qwen3:4b`.
4. Запусти `start.bat`.
5. Открой http://127.0.0.1:8790
6. Разреши браузеру доступ к микрофону.
7. Нажми «🎙️ Говорить».

## Возможности

- голосовой ввод и голосовой ответ;
- запуск Блокнота, Калькулятора и Проводника;
- открытие сайтов и папок;
- движение и нажатие мыши;
- ввод текста;
- нажатие разрешённых клавиш;
- получение состояния ПК;
- скриншот.

Произвольные cmd/PowerShell-команды и удаление файлов намеренно не добавлены.

Это отдельный локальный KAI, а не модель ChatGPT из этого чата.
