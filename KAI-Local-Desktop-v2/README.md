# KAI Local Desktop v2

Локальный чат для Windows на базе Ollama. Без API-ключей и оплаты за запросы.

## Возможности
- Современный адаптивный интерфейс на русском языке.
- Чат с локальной моделью через Ollama.
- Автоматическое обнаружение установленных моделей.
- Голосовой ввод через распознавание речи браузера, если оно поддерживается.
- Озвучивание ответов средствами браузера.
- Ошибки микрофона и модели показываются в интерфейсе, а не оставляют его в вечном ожидании.

## Установка
1. Установи Python 3.10+: https://www.python.org/downloads/windows/
2. Установи Ollama: https://ollama.com/download/windows
3. Скачай репозиторий и открой папку KAI-Local-Desktop-v2.
4. Запусти setup.bat и дождись загрузки qwen3:4b.
5. Запусти start.bat.
6. Откроется http://127.0.0.1:8790.

## Важно
- При первом скачивании модели нужен интернет. После загрузки модели текстовый чат работает локально.
- Скорость и качество зависят от компьютера и модели.
- Распознавание речи браузера может зависеть от браузера и подключения к интернету; сам текстовый чат работает без микрофона.
- Сервер слушает только 127.0.0.1 и не предназначен для доступа из сети.
- Это локальная модель, а не ChatGPT.
